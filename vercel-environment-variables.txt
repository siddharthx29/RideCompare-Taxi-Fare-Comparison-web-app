HOW TO UPLOAD TO VERCEL:
------------------------------------------------------------------------------
METHOD 1 (Vercel Web Dashboard - Fastest):
  1. Open your project on Vercel: https://vercel.com/dashboard
  2. Go to: Settings -> Environment Variables
  3. Click "Import" or copy & paste the block below into the input box
  4. Select environments: Production, Preview, Development
  5. Click "Save"
  6. Trigger a new deployment (Deployments -> Redeploy)

METHOD 2 (Using Vercel CLI):
  Run the following command from the root directory:
  vercel env pull .env.local

KEY NOTES ON SPECIFIC VARIABLES:
------------------------------------------------------------------------------
1. VITE_API_URL:
   - For full-stack deployment on Vercel (recommended), leave VITE_API_URL blank!
     vercel.json automatically routes /api/* to the serverless Python backend.
   - If your backend runs on an external server (e.g., Render), set:
     VITE_API_URL=https://ridecompare.onrender.com

2. DATABASE_URL:
   - If you add the Neon PostgreSQL integration via Vercel Marketplace,
     Vercel will automatically provide DATABASE_URL and POSTGRES_URL.
   - If using SQLite on Vercel serverless, the backend will automatically
     use an ephemeral database at /tmp/ridecompare.db.

3. MAPBOX vs. FREE FALLBACK:
   - If you have Mapbox tokens, set MAPBOX_ACCESS_TOKEN and MAPBOX_PUBLIC_TOKEN.
   - If you do NOT have Mapbox tokens, change GEOCODING_PROVIDER to:
     GEOCODING_PROVIDER=photon
     (Photon uses OpenStreetMap and is 100% free with no API key needed).
